# 中文技术文档与学术文档（DOCX）

用于产出或改写中文 DOCX：实验报告、课程大作业、课程论文、项目/技术报告、调研报告。核心是两件事——**版式必须合规**，**数据不完整时也必须写成一份完整的稿子**。

## 何时启用

- 用户要求写/改中文报告、大作业、论文，或给出 `.docx` 模板要求"照这个格式写"。
- 用户提到字号、行距、首行缩进、三线表、公式编号等版式要求。
- 用户给出原始数据（表格、截图、旧稿）要求整理成正式文档。
- 已知课程模板：北航《自动控制原理》实验报告模板（见"结构"一节）。

开工前先确认三件事：**文档类型**（实验报告 / 大作业 / 论文）、**是否沿用既有模板**、**交付格式**（DOCX 为主）。其余细节按本文默认值执行，不要反问用户一堆格式问题。

## 一、版式规格（硬性，优先于模板默认值）

| 元素 | 规格 | OOXML |
|---|---|---|
| 正文 | 宋体 + Times New Roman，**小四 12 pt** | `w:sz=24` |
| 正文行距 | **1.5 倍** | `w:spacing line="360" lineRule="auto"` |
| 正文缩进 | **首行缩进 2 字符** | `w:ind firstLineChars="200" firstLine="480"` |
| 正文对齐 | 两端对齐，段前段后 0 | `w:jc=both` |
| 章标题 | 宋体 **四号 14 pt 加粗** | `w:sz=28` `w:b` |
| 小节标题 | 宋体 **小四 12 pt 加粗** | `w:sz=24` `w:b` |
| 表格文字 | 宋体，五号 10.5 pt 或小五 9 pt（全套统一），表头加粗 | `w:sz=21` / `18` |
| 图表题 | 宋体 五号 10.5 pt，居中 | `w:sz=21` |
| 表注 / 图注（口径说明） | 宋体 小五 9 pt，左对齐，紧贴对象下方 | `w:sz=18` |
| 页面 | A4，上下 2.5–3 cm，左右 2–3 cm（沿用模板） | — |

要点：

- **中文字号换算**：初号 42 / 小初 36 / 一号 26 / 小一 24 / 二号 22 / 小二 18 / 三号 16 / 小三 15 / **四号 14** / **小四 12** / **五号 10.5** / 小五 9（单位 pt，OOXML 里是半磅，即 ×2）。
- **中文必须写 `w:eastAsia`**：只设 `run.font.name` 只改西文字体，中文会退回默认宋体或楷体。三个属性一起写：`w:ascii`、`w:hAnsi` 用 Times New Roman，`w:eastAsia` 用宋体。
- **模板常自带五号（sz 21）**：改写既有模板时，样式里的 10.5 pt 会盖掉你的意图，必须在样式定义或每个 run 上显式覆盖，并回读 XML 确认 `w:sz="24"`。
- **标题不要改成黑体**：本规格要求"宋体加粗"，用 `w:b` 表达层级；黑体会与正文割裂，也不符合"同族字体靠字重分层"的要求。若课程模板原本就是黑体，两者冲突时以用户本次指定为准。
- **行距与网格**：文档启用"对齐到网格"时，1.5 倍行距会被重新量化成近似值。段落属性加 `w:snapToGrid w:val="0"`，或整篇关闭网格对齐。
- **段距**：章标题段前 12 pt、段后 6 pt；小节标题段前 6 pt、段后 3 pt；正文段前段后 0（靠行距撑开，不要用空行）。
- **不允许**：用空行凑版面、用连续空格做对齐、用下划线模拟表格、正文里混用两种字号。

## 二、结构

### A. 实验报告骨架（北航模板）

```
封面        成绩栏 / 校名院徽页眉 / 课程名 + "实验报告" / 院（系）、学号、姓名 / 实验日期
正文首页    实验名称（Title 样式）/ 实验时间　座位编号　同组同学
一、实验目的                    3 条，编号 1./2./3.，动词开头
二、实验原理与系统模型           1 一阶模型　2 二阶模型（公式在此给全）
三、实验装置与实验方法           平台、接线、采集设置、指标提取口径
四、实验数据与结果               1 各组参数与指标表　2 响应曲线
五、结果计算与分析               归一化检验、趋势解释、误差量化、思考题
六、思考题                      课程未布置则整章删除，不要写"本次无思考题"
七、实验结论                    3–5 句，只写测到了什么、成立什么
八、收获、体会与改进建议          4–5 段连贯文字，不用编号列表
参考资料                        ≥2 条，可核对（指导书页码、教材、官方文档）
```

### B. 大作业 / 课程论文骨架

```
封面        题目 / 课程名称 / 姓名 学号 院系 / 日期
摘要        200–300 字：问题、方法、主要结果（含关键数字）、结论；关键词 3–5 个
一、引言      背景与问题、已有做法不足、本文工作与贡献（一段说清）
二、理论基础   定义、假设、公式、符号表
三、方法与实现 模型/算法/系统设计，配流程图或结构图
四、实验与结果 数据、对照、图表；先给判据再给结果
五、讨论      误差来源、适用条件、与已有工作比较
六、结论与展望 3–5 条，可执行
参考文献      GB/T 7714
附录（可选）   代码、完整数据表、推导
```

### 合并规则

- 短报告（≤8 页）用四章紧凑式：**目的 / 过程与结果 / 结果分析 / 收获**，层级与字体规格不变。
- 理论推导少时，"理论基础"并入"方法与实现"。
- 无思考题就删掉该章；无附录就不写附录。
- 编号只用一种：章用"一、二、三"，节用"1 2 3"或"1.1 1.2"，全文统一，不混用"（一）"和"1."。
- 目录/页码：≥10 页才加目录；页码从正文起算，封面不编号。

## 三、数据不完整时的写法（本 skill 的核心）

原则：**数据可以不全，稿子不能看起来没做完。** 防御性表述不是严谨，是把工作推给读者。

1. **记录值只当"实测"，不当"结论"。** 表里抄来的理论值一律重算，用重算值做分析基准；记录值作为对照列保留，差异在表注里一句话说明（判据不同 / 取整 / 近似公式）。
2. **先定口径，再算数。** 误差带（±5%）、稳态值估计、指标定义、ζ 与元件的关系式，必须在动笔前固定，全文只用一个。口径写在方法一节，不要反复声明。
3. **缺失项按判据归零或记"未检出"。** 超调低于阈值就写"峰值未越过 5% 边界，记为 0.00%"，并在表注交代一次。不要写"该项数据缺失"。
4. **禁止防御性词汇**：待补、待核、需核实、尚不能、不足以、未提供、不推定、不能据此、仅作记录、材料不包含、单位不明、数据边界、不确定性、本次实验不够完善/不够严谨/受条件限制。
5. **"不确定"要转成"确定的口径"**：不写"单位尚不明确"，改写"时间以 s 计，按软件显示位数记录"。
6. **结论用肯定句**：给方向 + 量级（"T 增大时 Tₛ 随之增大，实测比值与理论值偏离不超过 4%"），不要用"可能/也许"串成段。
7. **降级策略**：能算的算（表内自洽）、不能算的不写、绝不编造。宁可少一张表，不留一句"待补"。
8. **只借结构与论证方式，不借数值。** 参考别人的报告时，一个数字都不许搬。

改写对照：

| 防御性原稿 | 改写后 |
|---|---|
| 工作簿未说明 Tₛ 单位，需核实 | 时间单位统一为 s，数值按软件显示位数记录 |
| 理论调节时间是否按该判据计算，仍待核对 | 理论值按 ±5% 误差带重算，与实测同判据比较 |
| 材料不足，不计算相对误差 | 以重算理论值为基准，相对误差见表 3 |
| F 组表列零超调与曲线轻微峰值矛盾 | F 组峰值未越过 5% 边界，软件记为 0.00% |
| 数据存在不确定性，结论仅供参考 | 七组误差落在 −4.1%~+8.0%，模型成立 |

## 四、定量分析的最低要求

任何"结果分析"章至少包含下面四件事，缺一件就补上：

1. **判据先于数字**：先说清用什么判据、什么误差带、如何取稳态值。
2. **归一化检验**：找一个与绝对尺度无关的无量纲量验证模型，例如一阶 `Tₛ/T = 2.9957`、二阶 `σ% = exp(−πζ/√(1−ζ²))`。比值成群落在理论值附近，比堆误差更有说服力。
3. **误差表**：`δ = (实测 − 理论)/理论 × 100%`，超调差用**百分点**不用百分号；给范围（min~max）、给方向（正负是否一致）、给归因（参数类 / 提取类）。
4. **结论要能落地**：解释"为什么"，例如阻尼增大先压振荡、接近临界阻尼后单调趋稳更慢，因此 Tₛ 先降后升。

数值规范：时间保留 4 位小数，百分比与误差 2 位小数；负号用 `−`（U+2212）不用连字符；乘号 `×`；数字与单位间加空格（`0.2397 s`）；百分数紧贴数字（`43.90%`）。先算完写进一份数值清单，正文只引用清单，禁止正文与表格各算一遍。

## 五、公式

**必须用 Word 公式编辑器（OMML）或 LaTeX 转换产物，禁止截图、禁止用纯文本符号堆公式。**

- 行间公式单独成段、居中；需要编号时用右对齐制表位，编号 `(1)` 或按章 `(2-1)`，全文连续。
- 变量斜体、单位正体；公式内标点用半角；公式后接"式中……"逐符号说明，只说明一次。
- 复用已有公式：从含同类公式的 docx 里 `deepcopy` 整个 `<m:oMath>` 段落再插入，Word 里仍可编辑。
- 新建公式：直接注入 OMML 片段（下例已在 Word/LO 验证可渲染）。

```python
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml import parse_xml
from docx.oxml.ns import nsdecls

# p 为已创建的段落；下面给行间分式 1/(Ts+1)，继续拼 m:sup / m:sub / m:rad 即可
omml = (
    f'<m:oMath {nsdecls("m", "w")}>'
    '<m:f><m:num><m:r><m:t>1</m:t></m:r></m:num>'
    '<m:den><m:r><m:t>Ts+1</m:t></m:r></m:den></m:f>'
    '</m:oMath>'
)
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
p._p.append(parse_xml(omml))
```

- LaTeX 稿：环境里有 pandoc 时用 `pandoc -f latex -t docx` 生成 OMML，再按样式合并；没有 pandoc 就复制同类公式改符号。
- **LibreOffice 预览常给公式画细框**，那是预览器的显示习惯，XML 中并无边框。不要为了消除它去改公式或加白底。

## 六、图表与参考文献

- **图**：同一文档图宽一致（A4 版心 16 cm 时用 15–15.2 cm）；截图先裁掉四周空白，让图内字号与其它图接近；分辨率低于 150 dpi 的图不要放大到满宽，宁可缩小显示宽度。每张图配一句指标说明（"σ=43.90%，Tₛ=11.28 s"），图题在图下方。
- **表**：三线表（顶线/表头线/底线 1.5/0.75/1.5 磅）或全框线，**全套只用一种**；表题在表上方；单位写进表头（`Tₛ 实测 / s`）；行不跨页（`w:cantSplit`），跨页时表头重复（`w:tblHeader`）；数字列右对齐或小数点对齐。
- **表注**：写口径与来源，一句话（"注：ζ 反算值由 ζ=1/(2ωₙR₄C₂) 求得"），紧贴表格下方，不另起一节。
- **参考文献**：GB/T 7714；每条能核对到（作者. 题名. 来源, 年: 页码 或 URL）；正文用 `[1]` 标注；不写"待补"、不写"内部资料"。
- 图表编号连续，正文按"如表 3 所示""见图 4"引用，编号与内容对得上。

## 七、用 python-docx 落地的关键配方

优先 `python-docx`；环境里没有就调用 `load_workspace_dependencies` 取自带 Python，不要擅自安装包。

**正文与标题**（已核对生成的 XML）：

```python
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn
from docx.shared import Pt

def style_run(run, size, east="宋体", bold=False):
    run.font.name = "Times New Roman"          # w:ascii / w:hAnsi
    run.font.size = Pt(size)                   # 小四=12, 四号=14
    run.font.bold = bold
    rPr = run._element.get_or_add_rPr()
    rPr.rFonts.set(qn("w:eastAsia"), east)     # 中文字体必须单独设

def body(doc, text):
    p = doc.add_paragraph()
    pf = p.paragraph_format
    pf.line_spacing = 1.5                      # 1.5 倍行距
    pf.space_before = Pt(0); pf.space_after = Pt(0)
    pf.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY
    ind = p._p.get_or_add_pPr().get_or_add_ind()
    ind.set(qn("w:firstLineChars"), "200")     # 首行缩进 2 字符
    ind.set(qn("w:firstLine"), "480")          # 兼容值（2×12pt=480 twips）
    style_run(p.add_run(text), 12)
```

**沿用模板改写**：保留封面与 `sectPr`，删掉其后的正文节点，再按模板段落"克隆"出新段落，可完整继承原有 `pPr`（缩进、段距、编号）。删段落时顺手 `drop_rel` 掉不再引用的图片关系，否则包体会留下孤儿图片。

**表格**：`tblLayout=fixed` + 显式 `tblBorders` + `tblGrid` 列宽 + 每行 `cantSplit` + 首行 `tblHeader`；除最后一行外，各单元格段落设 `keep_with_next`，让整表尽量不被拆开。`tblPr` 子元素顺序须按 schema 排列（`tblW, jc, tblBorders, tblLayout, tblCellMar, tblLook`），顺序错 Word 会报损坏。

**图片**：`run.add_picture(path, width=Cm(15.2))`；先用 Pillow 裁掉四周白边（`ImageChops.difference` + `getbbox`，留 12–16 px 余量），否则不同截图缩放后字号差异明显。

**排版链**：标题 → `keep_with_next`；表题/图题 → `keep_with_next` 指向表格或图片；表格最后一行不设，避免把表尾拉到下一页。

**不要**手工插分页符凑版面；靠内容与段距自然流动，成稿后渲染逐页检查，只修孤行、孤表、表图被拆这类具体问题。

## 八、工作流

1. **读料**：源稿、模板、范文、数据文件全部读一遍，抽出"数据表 / 公式 / 图片"三类资产清单。
2. **定口径**：判据、误差带、稳态值、元件与参数关系式，写成一句话清单，后续不再改。
3. **先算后写**：用脚本算出全部理论值、比值、误差，产出数值清单（这是防止正文与表格打架的唯一办法）。
4. **搭骨架**：选 A 或 B 骨架，把素材按章归位；缺失章节直接删，不留占位。
5. **落版式**：样式/run 显式覆盖字号行距缩进；公式走 OMML；表格图按第六节。
6. **校验**：回读 DOCX 扫禁用词、核对数字、图表编号、章节顺序；渲染逐页看分页与表格拆分。
7. **交付**：说明改了哪几处、哪些需要手填（仅封面个人信息）、遗留风险一句话带过。

## 十、反模式

- 用 `paragraph.text = "..."` 改字——会清掉 run 的全部格式。
- 只设 `font.name` 不设 `w:eastAsia`——中文变字体。
- 把公式、表格、程序输出截成图片贴进去。
- 把源表里的"理论值"直接当基准，导致结论跟着错。
- 写"数据不足，仅供参考"来代替算一遍。
- 混用五号与小四、三线表与全框线、两种节编号。
- 用空行、连续空格、分页符堆版面。
- 正文数字与表格对不上（两处各算一遍的必然结果）。
- 把范文的数值、结论、图注直接搬进自己的稿子。
